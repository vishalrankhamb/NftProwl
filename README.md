# NftProwl

NftProwl facilitates cross-chain, nft-agnostic data streaming and validation via auto-scaling real-time processing engines.

The key benefits of using NftProwl include:

- NftProwl facilitates cross-chain, nft-agnostic data
- streaming and validation via auto-scaling
- real-time processing engines

## Technology Stack

- typescript
- typescript framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/vishalrankhamb/NftProwl.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
